# LinnPol
Linnade põletamise programm

Mäng on kahe inimesega, algul sisestatakse kahe inimese nimi. Iga hetk saab mängu lõpetada kui kirjutada q.
Vajutades ükskõik mis muud nuppu, mõlemad mängijad tõmbavad pakist suvaliselt ühe kaardi. Tugevam kaart võidab.
Mängu lõpus see, kes võitis kõige rohkem lahinguid võidab mängu

Koodis ise algul jaotakse klassidesse kaardid ja nende mastid.
Kaari klassis antakse kaartidele väärtused. Seal toimub kaartide võrdlus.
Pakk klassis "eemaldatakse" kaarte et need uuesti ei ilmuks.
Mäng klassis mäng hakkab tööle.
Viikide puhul tugevust järjestus on poti, ärtu, risti, ruutu.
Koodi saab veel arendada, näiteks lisada mis juhtub kui viik numbrite vahel toimub, et see ei arvestaks masti.
